# Data

This repository does not ship any dataset. `src/train.py` expects a folder
of live images and (optionally) one or more folders of spoof images;
`src/evaluate.py` additionally expects a real-only validation folder and a
real+spoof test folder. See each script's CONFIG block.

Datasets used in the paper:

- [ ] OULU-NPU
- [ ] MSU-MFSD
- [ ] Replay-Attack
- [ ] CASIA-MFSD
- [ ] SiW-Mv2
- [ ] WMCA
- [ ] ROSE-Youtu
